# Путеводитель по Нижнему парку Петергофа

Telegram-бот на `pyTelegramBotAPI`. Можно открыть карту Нижнего парка, посмотреть достопримечательности и задать вопрос виртуальному гиду.

## Запуск

1. Создайте файл `.env` по образцу `.env.template`.
2. Укажите токен бота от [@BotFather](https://t.me/BotFather) в `BOT_TOKEN`.
3. Установите зависимости:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Команды:

- `/start` — описание бота
- `/guide` — путеводитель по Нижнему парку
- `/question` — вопрос о Петергофе
- `/help` — список команд

Фотографии достопримечательностей лежат в `assets/peterhof/`. Источники и лицензии — в `assets/peterhof/SOURCES.md`.

## Настройка AI (`/question`)

Бот отправляет вопрос в [OpenRouter](https://openrouter.ai/) и использует бесплатный роутер моделей `openrouter/free`.

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/).
2. Создайте API key в разделе Keys.
3. Добавьте ключ в `.env`:

```
OPENROUTER_API_KEY = "Ваш ключ OpenRouter"
```

Не добавляйте ключ в код и не публикуйте `.env`. Файл уже указан в `.gitignore`.

Как работает `/question`:

1. Пользователь вызывает `/question`.
2. Бот просит сформулировать вопрос о Петергофе.
3. Следующее текстовое сообщение уходит в OpenRouter.
4. Ответ приходит в чат. Если сервис недоступен, бот сообщает об ошибке без технических деталей.
